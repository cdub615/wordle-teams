## Before you start

- [ ] **Nothing on port 3000.** `ss -ltnp | grep :3000`. A leftover `vite dev`
      serves whatever code it last loaded, and every e2e result taken against it
      is meaningless (`wordle-teams-9mjm` — a two-day-old server invalidated a
      week of runs).
- [ ] **Do not inspect a fetched page with `grep`.** Every SSR document this app
      serves contains NUL bytes — TanStack serialises route ids with a trailing
      NUL — so `grep` treats the response as binary and reports **no matches,
      with no error**. It looks exactly like the content being absent, and it
      already produced one false conclusion (that the landing page was
      client-rendered and invisible to crawlers, when it was fully
      server-rendered). Use `grep -a`, `tr -d` the NUL, or a real parser.

      *This document could not be written into the repo on the first attempt
      because the paragraph above contained a literal NUL. The trap is live.*
